How to use

  • Hand grab and move any sticky or text
  • Sticky pick a color, then click the canvas to place a note
  • Text click the canvas to place a text box
  • Pen and Eraser draw or remove ink in the selected color
  • Sticky library pre-written notes on the right, click or drag to add
  • Upload PDF each page becomes its own frame you can annotate
  • Frames add, switch, and remove slides on the left
  • Export download the board as JSON
