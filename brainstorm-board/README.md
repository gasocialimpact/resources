# Brainstorm Board

A lightweight Jamboard style brainstorming tool. Single HTML file, no build step.

Open `index.html` locally or visit the hosted page once GitHub Pages is on for this repo.

Features
- Landing page to create a new board from a blank frame or a starter layout
- Hand tool to move stickies and text, plus sticky, text, pen, and eraser tools
- Sticky library with pre-written notes you can click or drag onto a frame
- Upload a PDF and each page becomes its own frame sized to the page
- Boards auto-save on your device and appear on the landing page
- Share link copies a URL that opens the board for anyone (PDF pages are left out of links, use Export for those)
- Export and import boards as JSON
